## Dependency audit boundary

The post-patch dependency audit recorded **0 high, 0 critical, and 2 moderate entries** after pinning `js-yaml` to `4.3.2`. Both moderate entries refer to the same development-tool advisory, [GHSA-82fw-gwwq-j7x9](https://github.com/vitest-dev/vitest/security/advisories/GHSA-82fw-gwwq-j7x9), through `vitest` and `@vitest/mocker` at `3.2.6`. The advisory concerns redirect mocks reading files outside a development server's allowed paths. Its maintained stable fix is `4.1.11`; the maintainer does not plan a 3.x backport.

These checks use `vitest run`; no Vite/mocker/browser-RPC server is exposed as part of the hosted application, and this tooling is not its deployed runtime. The major test-tool upgrade is **DEFERRED**. This is not an all-vulnerabilities-clear claim. Private audit evidence: `hosting-dependency-audit-patched.log`.
